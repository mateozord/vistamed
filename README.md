# Vistamed

Proposta de redesign conceitual para uma clínica oftalmológica, com agendamento integrado ao WhatsApp.

🔗 [vistamednew.netlify.app](https://vistamednew.netlify.app)

## Sobre

Projeto de front-end estático focado em UI/UX: página institucional com unidades, informações da clínica e botão de agendamento que abre diretamente uma conversa no WhatsApp.

## Tecnologias

- HTML
- CSS
- JavaScript
